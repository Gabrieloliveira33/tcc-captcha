# tcc-captcha
Projeto de TCC focado na avaliação experimental da efetividade de mecanismos CAPTCHA na mitigação de ataques automatizados em aplicações web. O trabalho envolve o desenvolvimento de uma aplicação web com CAPTCHA, utilização de bots adaptados para simulação de ataques e análise de métricas como taxa de bloqueio, evasão e usabilidade.
